五、竞争优势

  • 高频消费入口和商户网络壁垒明显。
  • 履约体系、算法调度和本地供给组织能力强。
  • 现金储备较高，有能力应对阶段性竞争。

六、主要风险

  • 竞争加剧导致补贴和营销费用上升。
  • 骑手、平台治理、费率等监管约束。
  • 新业务拖累利润，估值对盈利恢复敏感。

七、跟踪指标

建议后续重点跟踪：

1. 收入增速是否与行业景气和市场份额变化一致；

2. 毛利率、经营利润率是否出现趋势性改善；

3. 自由现金流与现金储备是否足以支撑扩张；

4. 核心业务的竞争格局、监管环境和价格策略；

5. 新业务是否贡献增量价值，而不是持续消耗现金。
